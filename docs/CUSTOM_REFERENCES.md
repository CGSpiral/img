# CUSTOM REFERENCES — reference board

How to submit: put images in `references/<category>/` in this repo (or attach them in chat),
with a short note on what you like about each. I log each one with an ID, what it influences,
and the decisions derived from it. References shape the look but are never shipped.

## What each category influences

| Category | Influences |
|---|---|
| Architecture | Modular building kit, silhouettes, roof lines, materials |
| Buildings and city layout | Street grid, block sizes, sightlines, verticality |
| Terrain and landscape | Terrain materials, elevation, water, cliffs |
| Lighting, sky, fog, atmosphere | Lighting technology, Atmosphere density and haze, Sky, ColorCorrection, Bloom |
| Arena shapes and landmarks | Combat-space dimensions, cover density, focal landmarks |
| Dungeons, gates, portals, interiors | PvE instance kit, gate set pieces, transition VFX |
| Destruction and battle damage | Craters, debris VFX, damaged-building variants |
| Colour palette and mood | UI palette, VFX colours per character, post-processing |
